This creates the data for the CTPMA.

The Data Bricks notebook `CTPMA notebook.ipynb` is used to gather the data on each TPMA and the counts of all mitigable and usual activity in each activity type.

The R script `create_lookup_for_cptma.R` generates a lookup which is provided for context on each TPMA, particularly what the rate is and the type (activity avoidance / efficiencies).

The final lookup is `combined_mitigation_lookup_rates.csv` which is generated by combining `mitigator_lookup.csv` and `golem-config.yml` in the above script.
